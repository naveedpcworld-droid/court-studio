# ⚖️ Courtroom Studio — START HERE

Is folder ko Claude Code mein kholo aur bas likho:

> **"court video banao"** (ya seedha YouTube link paste karo)

Claude tum se 3 cheezein poochega — **source link**, **template (T1-T6)**, **length** — aur baaki sab
khud karega: download, transcript, (lambi video ho to) best case nikaalna, commentary script,
narrator voice, editing, captions, render, aur title/description/tags.

Templates dekhne hain? `templates/ALL-TEMPLATES.jpg` kholo, ya har template folder ka `sample.mp4`.

Claude ke liye poori instructions: `CLAUDE.md`.
